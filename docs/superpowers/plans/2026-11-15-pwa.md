# PWA Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Installable, offline-capable (recent recipes) Foodyz PWA with a polished manifest and install affordance.

**Architecture:** Hand-written classic service worker in `public/`, registered by a production-only client component; proxy exempts only the SW script and offline page; install UX via a small hook surfaced in `MoreSheet`.

**Tech Stack:** Next.js 16 (read `node_modules/next/dist/docs/01-app/02-guides/progressive-web-apps.md` first), React 19, Vitest, Playwright. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-15-pwa-design.md`

## Global Constraints

- pnpm only; `@/` imports; `interface` for props; localStorage access in try/catch; single light theme.
- Proxy exemptions are exact (`sw.js$`, `offline.html$`); nothing else becomes public. Update AGENTS.md's "Proxy matcher exemptions" bullet.
- SW registered only when `process.env.NODE_ENV === "production"`.
- Service worker caches only GET responses with `response.ok && !response.redirected`; never `/api/*`, `/login`, RSC (`RSC` request header) or non-GET.
- Commit prefix `feat:`; end messages with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Run `pnpm test`, `pnpm build` before done.

## Review Focus

- Logged-out `GET /sw.js` and `/offline.html` return 200 (not a redirect to `/login`); `/sw.jsx`-style lookalikes stay gated.
- Login redirect responses must never be cached as a recipe page (would trap offline user on login HTML).
- After logout, no private page remains in Cache Storage.
- Old cache versions are deleted when the SW updates (no unbounded growth).
- `/sw.js` is never served from HTTP cache (stale worker can't be fixed otherwise).
- Hook handles missing `beforeinstallprompt`, already-installed (standalone) and dismissed states without throwing when localStorage is blocked.
